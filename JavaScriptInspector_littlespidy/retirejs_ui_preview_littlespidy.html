# Severity Identifier / CVE Affected Versions Issue Summary
HIGH SEVERITY

CVE-2015-9251: 3rd party CORS request execution

Description and Security Impact

jQuery versions prior to 3.0.0 are vulnerable to Cross-Site Scripting (XSS). When using $.ajax() with dataType 'script' or when cross-domain requests without an explicit dataType are executed, responses from third-party or untrusted servers may execute arbitrary JavaScript in the context of the vulnerable application.

Remediation Guidance

Upgrade jQuery to version 3.5.0 or later. If upgrading is blocked by legacy plugins, configure $.ajaxSetup({ dataType: 'json' }) or enforce strict CORS policies to avoid auto-evaluating untrusted responses.
