Burp Suite Installation Guide
How to load the downloaded extensions into Burp Suite:
  1. Go to the Extensions tab in the main Burp Suite navigation bar.
  2. Select the Installed sub-tab.
  3. Click the Add button on the left panel.
  4. Ensure Extension type is set to Java.
  5. Click Select file... and navigate to your download folder: ~/Downloads/burpsuite-extensions/.
  6. Select any downloaded .jar file and click Next.
  7. The extension will load immediately and register its tabs, context menus, and tools.
